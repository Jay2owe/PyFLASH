# Changelog

## 0.2.0 - 2026-08-26

- Add self-describing master SVG figures with exact plotted data, statistics,
  software/run provenance, source fingerprints, and reproduction records.
- Add privacy-validated public and minimal-public figure profiles plus batch
  publication, extraction, inspection, captions, and catalogue commands.
- Add the reusable BSD-licensed ReproFig package as the package-neutral
  record, SVG, validation, and publication engine.
- Save SVG, PDF, PNG, JPEG, TIFF, WebP, AVIF and HEIF variants with one figure
  identity, configurable resolution and optional proof policies.
- Expose one-call ReproFig saving and publication-workbook helpers without
  requiring users to construct checksums or record JSON manually.
