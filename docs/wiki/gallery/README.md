# Gallery

## Visual Index

See the [Plot Gallery](plot-gallery.md) for a rendered example of every plot
function, grouped by family and linked to its reference page. All figures come
from one seeded [synthetic example dataset](../examples/README.md).

## Goal

Find small PyFLASH examples that can be copied into a Python session and
adapted to a real batch, table, or image set.

## Code

Start with the page that matches the task:

| Page | Pattern |
|---|---|
| [Load Table With from_dataframe](load-table-with-from-dataframe.md) | Wrap a small `pandas.DataFrame` as a PyFLASH object. |
| [Mean Bars Basic](mean-bars-basic.md) | Draw one group-comparison bar plot. |
| [Grouped Mean Bars](grouped-mean-bars.md) | Plot a crossed table by one factor. |
| [Correlation Matrix](correlation-matrix.md) | Draw a square marker correlation matrix. |
| [Plot Spec Batch](plot-spec-batch.md) | Run several registered plots from a JSON spec file. |
| [Small Model Sweep](model-sweep-small.md) | Run a compact classifier feature sweep. |
| [Image Grid](image-grid.md) | Build an image table and browse imported image paths. |
| [Representative Panels](representative-panels.md) | Render stored representative-image selections. |

## Result

Each page shows one focused pattern, the expected return value or saved-file
behavior, and links back to the longer reference pages.

## Notes

The table examples use synthetic data. The image examples generate temporary
synthetic PNG files inside the script so they demonstrate the required metadata
without committing rendered outputs.
