# Workflows

Workflow pages show how common tasks fit together across PyFLASH objects,
functions, plots, and saved outputs. They are not exhaustive parameter
references; each page links to the detailed function and output pages.

## Start With Data

| Page | Use it when |
|---|---|
| [Create a batch](create-a-batch.md) | You have FLASH/ImageJ experiment folders and want a reusable `Batch`. |
| [Build groups](build-conditions.md) | You need simple, comparison, or crossed group metadata before importing or plotting. |
| [Load and rebase a pickle](load-and-rebase-a-pickle.md) | You already have a saved PyFLASH `.pkl`, especially one moved between machines. |

## Make Plots And Pipelines

| Page | Use it when |
|---|---|
| [Plot from Python](plot-from-python.md) | You want direct plot calls in a script or notebook. |
| [Plot from a spec](plot-from-spec.md) | You want a reusable YAML, TOML, or JSON batch of plots and pipelines. |
| [Run correlation pipeline](run-correlation-pipeline.md) | You want pairwise correlations, matrix outputs, selected pairs, and optional regressions. |
| [Run adjusted linear model](run-adjusted-linear-model.md) | You want adjusted model coefficients, adjusted means, and contrasts. |
| [Run model sweep](run-model-sweep.md) | You want a classifier feature-subset discovery screen. |

## Save Or Use The UI

| Page | Use it when |
|---|---|
| [Export Excel workbooks](export-excel-workbooks.md) | You need collaborator-friendly `.xlsx` summaries from a `Batch`. |
| [Use the Streamlit UI](use-the-streamlit-ui.md) | You prefer the optional point-and-click interface for loading, plotting, and exporting. |
