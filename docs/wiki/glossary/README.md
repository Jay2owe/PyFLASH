# Glossary

Short definitions for common PyFLASH terms. Entries link to the deeper reference
page where the term is explained in context.

## Sections

- [Objects](objects.md): Python objects such as `Batch`, `Experiment`, groups,
  and markers.
- [Data](data.md): tables, columns, specs, manifests, ledgers, and pickles.
- [Microscopy](microscopy.md): imaging, ROI, marker, and measurement terms.
- [Plots](plots.md): plot families and common figure outputs.
- [Statistics](statistics.md): tests, model metrics, correction, and effect terms.
- [Parameters](parameters.md): common function keyword names and aliases.
