# Plots

## Mean Bars

Grouped summary bars with optional points and statistical annotations. See also:
[Mean bars](../plot-types/mean-bars.md).

## Matrix Plot

A heatmap-style plot of values across markers, regions, groups, or comparisons.
See also: [Matrix plots](../plot-types/matrix-plots.md).

## Rect Matrix

A rectangular matrix plot for non-square value layouts. See also:
[plot_rect_matrices](../functions/plot_rect_matrices.md).

## Matrix Difference

A matrix plot showing differences between groups or conditions. See also:
[plot_matrix_differences](../functions/plot_matrix_differences.md).

## Volcano Plot

A plot that combines effect or change size with statistical evidence. See also:
[plot_volcano](../functions/plot_volcano.md).

## Regression Plot

A plot of one variable against another with model or trend information. See also:
[Regression plots](../plot-types/regression-plots.md).

## Multivariable Regression Matrix

A matrix-style view of multivariable regression outputs. See also:
[plot_multivariable_regression_matrix](../functions/plot_multivariable_regression_matrix.md).

## Distribution Plot

A histogram, ECDF, or ridgeline view of value distributions. See also:
[Distribution plots](../plot-types/distribution-plots.md).

## Ridgeline

Stacked, smoothed density curves for comparing a value's distribution across many
groups in one figure (also called a joyplot). See also:
[plot_ridgeline](../functions/plot_ridgeline.md).

## ECDF

Empirical cumulative distribution function: a binless cumulative curve of a
value's distribution. See also: [plot_ecdf](../functions/plot_ecdf.md).

## Pie Chart

A categorical proportion plot. See also:
[plot_pie_charts](../functions/plot_pie_charts.md).

## Combo Pie

A pie chart for marker-combination categories. See also:
[plot_combo_pies](../functions/plot_combo_pies.md).

## Sankey Plot

A flow diagram for category transitions or relationships. See also:
[plot_coloc_sankey](../functions/plot_coloc_sankey.md).

## UpSet Plot

A set-intersection plot for marker combinations. See also:
[plot_coloc_upset](../functions/plot_coloc_upset.md).

## Radar Plot

A polar plot comparing multiple normalized measurements. See also:
[plot_radar](../functions/plot_radar.md).

## PCA Plot

A principal component analysis summary of marker features. See also:
[plot_marker_pca](../functions/plot_marker_pca.md).

## Timecourse Plot

A plot of values across ordered time points. See also:
[plot_timecourse](../functions/plot_timecourse.md).

## Power Curve

A plot estimating power across sample sizes or effect sizes. See also:
[plot_power_curve](../functions/plot_power_curve.md).

## Image Grid

A grid of imported microscopy images. See also:
[Image panels](../plot-types/image-panels.md).

## Representative Panel

A curated image panel built from representative image selections. See also:
[plot_representative_images](../functions/plot_representative_images.md).

## Location Plot

A spatial or location-based view of imported regions or objects. See also:
[Location plots](../plot-types/location-plots.md).

## Superplot

A grouped plot that emphasizes subject-level values as well as group summaries.
See also: [plot_superplot](../functions/plot_superplot.md).

## Effect Forest

A forest-style plot of effect sizes and confidence intervals. See also:
[plot_effect_forest](../functions/plot_effect_forest.md).

## Group Matrix

A matrix-style comparison of group-level effects. See also:
[plot_group_matrix](../functions/plot_group_matrix.md).

## Cosinor Plot

A rhythm plot from cosinor model outputs. See also:
[plot_cosinor](../functions/plot_cosinor.md).

## Acrophase Clock

A circular rhythm plot for phase timing. See also:
[plot_acrophase_clock](../functions/plot_acrophase_clock.md).
