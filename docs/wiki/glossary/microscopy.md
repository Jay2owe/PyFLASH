# Microscopy

## ROI

Region of interest, usually an anatomical or analysis area measured in images.
See also: [ROI parameters](../parameters/roi.md).

## Region

A broader location label used in summary and ROI tables. See also:
[ROI tables](../data-structures/roi-tables.md).

## Marker

An immunofluorescence channel or biological marker such as DAPI, NeuN, or GFAP.
See also: [Markers](../object-types/markers.md).

## Channel

An image channel associated with a marker or stain. See also:
[Image table](../data-structures/image-table.md).

## Object Marker

A marker used to identify objects or cells in an imported object table. See also:
[Marker tables](../data-structures/marker-tables.md).

## Attribute

A measured property associated with an object, ROI, or marker. See also:
[Marker tables](../data-structures/marker-tables.md).

## Colocalisation

The overlap or relationship between marker-positive populations or channels.
See also: [Colocalisation plots](../plot-types/colocalisation-plots.md).

## Combo

A marker-combination category used in colocalisation summaries and pie charts.
See also: [plot_combo_pies](../functions/plot_combo_pies.md).

## Intensity

A fluorescence measurement for a marker, often summarized per object or ROI.
See also: [Summary table](../data-structures/summary-table.md).

## Integrated Density

An intensity-like measurement that combines signal and area. See also:
[Marker tables](../data-structures/marker-tables.md).

## Count

The number of objects, cells, or marker-positive events in a selected region.
See also: [Mean bars](../plot-types/mean-bars.md).

## Area

A size measurement for objects, ROIs, or regions. See also:
[ROI tables](../data-structures/roi-tables.md).

## Volume

A 3D size measurement when exported by the imaging workflow. See also:
[Summary table](../data-structures/summary-table.md).

## Hemisphere

A left/right anatomical side label when present in source tables. See also:
[Filter By and row filters](../parameters/specificity.md).

## Section

A tissue section or slice identifier when present in imported data. See also:
[Marker tables](../data-structures/marker-tables.md).

## Representative Image

An image selected to stand in for a subject, group, marker, or ROI in a panel.
See also: [plot_representative_images](../functions/plot_representative_images.md).

## Scale Bar

A length annotation drawn on image panels when physical pixel size is available.
See also: [Image panels](../plot-types/image-panels.md).
