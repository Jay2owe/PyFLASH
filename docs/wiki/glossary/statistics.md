# Statistics

## P Value

A probability-scale test result used in many group comparisons. See also:
[Group comparisons](../statistics/group-comparisons.md).

## Q Value

An adjusted p value after multiple-testing correction. See also:
[Multiple testing](../statistics/multiple-testing.md).

## FDR

False discovery rate, a common correction target for many simultaneous tests.
See also: [Multiple testing](../statistics/multiple-testing.md).

## Effect Size

A scale of difference or association that is separate from the p value. See also:
[Effect sizes](../statistics/effect-sizes.md).

## Hedges g

A standardized mean-difference effect size with small-sample correction. See also:
[Effect sizes](../statistics/effect-sizes.md).

## Confidence Interval

A range estimate around a statistic or effect. See also:
[Effect sizes](../statistics/effect-sizes.md).

## Normality

Whether a distribution is close enough to normal for parametric assumptions.
See also: [Normality outputs](../outputs/normality-outputs.md).

## Nonparametric Test

A test used when parametric assumptions are not suitable. See also:
[Statistics options](../parameters/statistics-options.md).

## Posthoc Test

A follow-up comparison after an omnibus or multi-group analysis. See also:
[Group comparisons](../statistics/group-comparisons.md).

## Multiple-Testing Correction

Adjustment for testing many columns, groups, or contrasts. See also:
[Multiple testing](../statistics/multiple-testing.md).

## Covariate

A variable included to adjust or explain an outcome in a model. See also:
[Linear models](../statistics/linear-models.md).

## Adjusted Mean

A model-derived group mean after accounting for covariates or design terms.
See also: [Linear models](../statistics/linear-models.md).

## Coefficient

A fitted model term describing direction and size of association. See also:
[Linear models](../statistics/linear-models.md).

## Residual

The difference between an observed value and the model-fitted value. See also:
[Linear models](../statistics/linear-models.md).

## Cross-Validation

A repeated train/test splitting method used to estimate model performance. See also:
[Classification](../statistics/classification.md).

## AUC

Area under the receiver operating curve for classification. See also:
[Classification](../statistics/classification.md).

## Balanced Accuracy

Accuracy averaged across classes so class imbalance has less influence. See also:
[Classification](../statistics/classification.md).

## Macro F1

An F1 score averaged across classes. See also:
[Classification](../statistics/classification.md).

## Permutation Test

A test that compares the observed result to results after shuffled labels or
assignments. See also: [Classification](../statistics/classification.md).

## Power

The chance of detecting an effect under a planned design and assumed effect size.
See also: [Power](../statistics/power.md).

## Cosinor

A sinusoidal model for rhythmic data. See also:
[Rhythm statistics](../statistics/rhythm.md).

## Acrophase

The phase or timing of a rhythm peak. See also:
[Rhythm statistics](../statistics/rhythm.md).
